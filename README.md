# Automatic upstream fork: zane-tv/tiktok-live-temple-rpc

This is a **public GitHub fork** of [zane-tv/tiktok-live-temple-rpc](https://github.com/zane-tv/tiktok-live-temple-rpc).

## Source code

Open the [main branch](https://github.com/052205001004/tiktok-live-temple-rpc-upstream/tree/main) for the original source code. All upstream branches and tags are synchronized daily. The default `sync-control` branch only stores automation and this guide; it remains separate from upstream code.

## Schedule and manual sync

Daily at approximately **03:17 Asia/Bangkok (UTC+7)**. GitHub may delay scheduled jobs. Run **Actions → Sync upstream → Run workflow** for an immediate update.

Upstream branch and tag updates replace the corresponding refs in this fork, preserving the upstream commit history. Keep your own work on a separate branch. Deleted upstream branches/tags are retained here. Other private copies in this account are independent and are not updated by this job.

The automation uses the built-in GITHUB_TOKEN with contents:write. It only fetches and pushes Git data and verifies reference hashes; it does not build, run, deploy, or install upstream application code. Inherited workflows are disabled. GitHub may reject upstream changes to workflow files that require additional permission; such cases appear as a failed Actions run and need owner review. No custom token is stored.

A monthly commit on `sync-control` maintains repository activity so the scheduled workflow does not lapse after prolonged upstream inactivity. Licenses and attribution from the original project remain in the source branches.
